# Archived Documents

This directory stores documents that have completed their purpose but retain historical research value.

## Rules

- Archived documents are read-only and are no longer updated
- New work must not cite archived documents as authority for current behavior, architecture, or product facts
- Current constraints must exist in `ARCHITECTURE.md`, `docs/STATE.md`, `docs/DECISIONS.md`, product specifications, or an adopted Design Doc
- When archiving a document, record its original location and archive reason in the table below
- Delete obsolete content with no historical value instead of archiving it for preservation's sake
- Repaid technical debt and completed or abandoned backlog items do not enter this directory; git and their carrying documents preserve the history
